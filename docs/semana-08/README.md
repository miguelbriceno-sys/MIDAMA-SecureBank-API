# Sesión 8 · DAST y seguridad de API

El análisis dinámico observó respuestas públicas de la API en una instancia efímera. Se usó ZAP 2.16.1 en modo pasivo y se verificó por HTTP la separación de perfiles con usuarios ficticios. El informe describe el alcance del rastreo, las cabeceras, los responsables y el resultado de ambas mediciones. El JSON conserva la salida original de la herramienta.
